Browser-supplied photo intake

Select the same Live Photo once with each option below. This page inspects the files the browser provides, before any page-side image conversion. Photos or the browser may already have changed the representation. Nothing is uploaded, displayed, or saved automatically. File names and raw metadata values are omitted from the report.

A photo identifier is not a video. Two supplied files are not automatically a verified Apple pair. No detected video is not proof that the original photo in your Photos library has no motion.

Reading is bounded to 32 MiB per file. Larger files are reported without inspecting their bytes. This diagnostic does not invoke PhotoKit, request a second resource, decode motion, or verify matching Apple resource identifiers.
